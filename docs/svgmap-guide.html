取得

カタログ取得

JAVASCRIPT
async function loadPublicCatalog() {
  const response = await fetch(
    "https://mosa-github.github.io/data_test_server_page/public-data/catalog.json"
  );

  if (!response.ok) throw new Error(`HTTP ${response.status}`);
  const catalog = await response.json();

  if (!Array.isArray(catalog.datasets)) {
    throw new Error("Unexpected response format");
  }
  return catalog.datasets;
}

承認済みデータの取得・POI更新

施設座標は公開承認されたマスターから取得し、facility_idで結合します。センサはsensor_idで識別します。座標未承認のセンサはPOIに描画しません。

import { loadApprovedSensors, updatePoiLayer, showSensor } from
  'https://mosa-github.github.io/data_test_server_page/assets/svgmap-data.js';

// svgDocument: MOSAdemyレイヤーのSVG文書（sensor-rootを持つ）
// iconUrl: そのレイヤーで利用する既存アイコンURL
// popup: 既存POIハンドラーが使う表示コンテナ
async function refresh() {
  try {
    const sensors = await loadApprovedSensors();
    updatePoiLayer(svgDocument, sensors, iconUrl, svgMap);
    const selected = sensors.find(s => s.id === selectedSensorId);
    if (selected) showSensor(popup, selected);
  } catch (error) {
    console.error('公開データ更新失敗'); // 現在のPOIを保持
  }
}
await refresh();
setInterval(refresh, 180000);
// 既存SVGMap: svgMap.setShowPoiProperty(handler, layerId) で
// POIのdata-sensor-idを選択しshowSensorへ渡す。

最新値: public-data/latest.json / 履歴: public-data/history.csv / 座標: public-data/locations.json / 許諾済み画像: public-data/cameras.json

カメラJSON

public-data/cameras.jsonのsensor_idをPOIキー、facility_idを施設結合キーとして使用。座標はlatitude / longitude、公開画像の取得URLはimage_urlです。

{
  "sensor_id": "CAM-X", "facility_id": "HOSP-X", "type": "camera",
  "name": "試験カメラ", "latitude": 34.65, "longitude": 133.92,
  "image_url": "https://mosa-github.github.io/data_test_server_page/public-data/images/0123456789abcdef0123456789abcdef.png",
  "content_type": "image/png", "width": 32, "height": 24,
  "measured_at": "2026-10-13T17:00:00+09:00", "status": "normal"
}

上記は形式の例です。実際の画像URLはJSONから取得してください。座標未承認はnull。画像未取得・再配布未承認はimage_url: null、status: "no_data"です。元のカメラURLやtokenは公開しません。推奨更新180秒。公開画像は同期時点の静止画です。

施設名・日本時間

public-data/locations.jsonのfacility_nameをfacility_idでセンサ・カメラへ結合します。施設名を結合キーにせず、承認済み施設マスターを使用してください。

公開JSON/CSVの日時は日本時間のISO 8601（+09:00付き）。画面は2026/10/13 17:00:00（日本時間）の24時間表示です。旧UTC（Z）も日時として読み取れます。

停電感知（SwitchBot）

データセットは既存のlatest（JSON）/ history（CSV）。type: "outage"を選び、sensor_idをPOIキー、facility_idを施設名・座標の結合キーに使用。推奨更新180秒、日時はmeasured_at（日本時間・+09:00）、共通状態はstatusです。

追加項目：power_state（NORMAL / 0W_ALERT / SWITCH_OFF / OFFLINE / BLE_WEAK / NODE_WEAK / UNKNOWN）、switch_on、ble_rssi、node_rssi、is_demo。消費電力はvalue/unit。通信途絶・未確認の値はnullで、停電確定ではありません。is_demo: trueは実測値と区別して表示してください。
