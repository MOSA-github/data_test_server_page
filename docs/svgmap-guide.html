公開カタログの読み込み

次のURLはこのサイトで実際に公開されるカタログです。

https://mosa-github.github.io/data_test_server_page/public-data/catalog.json

取得例

async function loadPublicCatalog() {
  const response = await fetch(
    "https://mosa-github.github.io/data_test_server_page/public-data/catalog.json"
  );
  if (!response.ok) throw new Error(`HTTP ${response.status}`);
  const data = await response.json();
  if (!Array.isArray(data.datasets)) {
    throw new Error("Unexpected response format");
  }
  return data.datasets;
}

レイヤー化の手順

  1. カタログから利用するデータセットURLを選ぶ。
  2. 各仕様に従いJSONまたはCSVを取得する。
  3. 有効な緯度・経度を持つレコードだけをPOIへ変換する。
  4. IDを安定キーとしてpopupへ名称、状態、最終更新を表示する。
  5. 更新失敗時は既存値を新しい値として扱わず、取得エラーを表示する。

SVGMap固有のレイヤー登録関数は利用中のSVGMap実装の仕様に従ってください。このページでは未確認APIを定義しません。
